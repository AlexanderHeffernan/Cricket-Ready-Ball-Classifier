# Front-End Styling

## Global Styles
- Defined in [`src/styles/global.css`](../frontend/src/styles/global.css)
- Uses CSS variables for color scheme:
  - `--primary`: #2E7D32
  - `--secondary`: #4CAF50
  - `--accent`: #C62828
  - `--background`: #F8F9FA

## Responsive Design
- Layout adapts for mobile and desktop.
- Buttons and containers scale for touch usability.

## Theming
- Color-coded feedback for predictions (green for ready, red for not ready).
