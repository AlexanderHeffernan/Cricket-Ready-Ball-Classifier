# Welcome to the Cricket-Ready Ball Classifier Documentation

Cricket-Ready Ball Classifier is a full-stack web application designed to help users determine if a cricket ball is match-ready using image classification powered by neural networks. The projects consists of a modern, mobile-friendly front-end for capturing and uploading images, and a robust back-end that processes predictions and manages training data.

The front-end is built with Vue.js and provides an intuitive interface for both prediction and data collection. The back-end, implemented in Rust and Python, handles image analysis, neural network interface, and API endpoints. Together, these components deliver a seamless experience for users and contributors.

Below you'll find documentation covering the architecture, user experience, development guidelines, and more to help you understand, use, and contribute to the project.
