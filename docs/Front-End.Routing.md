# Front-End Routing

The app uses Vue Router with the following routes:

- `/` or `/predict`: Main prediction interface ([`PredictView.vue`](../frontend/src/views/PredictView.vue))
- `/train`: Training tool for labeled data ([`TrainView.vue`](../frontend/src/views/TrainView.vue))

Navigation is available via the mode selector at the top of the app.
