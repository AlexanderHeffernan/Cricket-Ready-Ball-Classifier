# Environment & Dependencies

## Python Version

- Python 3.8 or higher recommended

## Virtual Environment

- Create with:
  ```bash
  python3 -m venv venv
  source venv/bin/activate
  ```

## Install Dependencies

- Install required packages:
  ```bash
  pip install -r requirements.txt
  ```

## Required Packages

- torch
- torchvision
- numpy
- pillow
- (see `requirements.txt` for full list)
